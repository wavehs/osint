# Руководство по установке и использованию ROBUST в Windows

Это руководство описывает шаги, необходимые для установки и запуска OSINT-фреймворка ROBUST в операционной системе Windows.

## 1. Установка необходимого ПО

Перед установкой фреймворка убедитесь, что у вас установлены следующие программы:

### a. Python 3

-   **Скачайте установщик:** Перейдите на официальный сайт [python.org](https://www.python.org/downloads/windows/) и скачайте последнюю версию Python 3.
-   **Установите Python:** Запустите установщик. **Важно:** На первом экране установки обязательно поставьте галочку "Add Python to PATH". Это позволит вам запускать Python из командной строки.
-   **Проверьте установку:** Откройте командную строку (`cmd` или `PowerShell`) и введите команду `python --version`. Вы должны увидеть версию установленного Python.

### b. Git

-   **Скачайте и установите:** Перейдите на сайт [git-scm.com](https.://git-scm.com/download/win) и скачайте установщик Git для Windows. Установите его, оставив настройки по умолчанию. Git необходим для клонирования репозитория проекта и его зависимостей.

### c. Nmap

-   **Скачайте установщик:** Перейдите на официальную страницу загрузки [nmap.org/download.html](https://nmap.org/download.html) и скачайте последнюю стабильную версию установщика для Windows (`nmap-<version>-setup.exe`).
-   **Установите Nmap:** Запустите установщик. В процессе установки убедитесь, что вы устанавливаете `npcap` (он будет предложен по умолчанию).
-   **Добавьте Nmap в PATH:** Установщик Nmap обычно предлагает добавить путь к программе в системную переменную `PATH`. Если этого не произошло автоматически, вам нужно будет сделать это вручную:
    1.  Найдите папку, куда вы установили Nmap (например, `C:\Program Files (x86)\Nmap`).
    2.  Найдите в Windows "Изменение системных переменных среды".
    3.  Нажмите "Переменные среды...".
    4.  В разделе "Системные переменные" найдите переменную `Path` и нажмите "Изменить".
    5.  Нажмите "Создать" и добавьте путь к папке Nmap.
-   **Проверьте установку:** Откройте новую командную строку и введите `nmap --version`. Вы должны увидеть информацию о версии Nmap.

## 2. Установка фреймворка ROBUST

### a. Клонирование репозитория

Откройте командную строку и перейдите в папку, где вы хотите разместить проект. Затем выполните команду:

```bash
git clone <URL репозитория>
cd <папка с проектом>
```

### b. Создание и активация виртуального окружения

Рекомендуется использовать виртуальное окружение, чтобы изолировать зависимости проекта.

```bash
# Создание виртуального окружения
python -m venv venv

# Активация виртуального окружения
.\venv\Scripts\activate
```

После активации в начале командной строки вы увидите `(venv)`.

### c. Установка зависимостей Python

Выполните команду для установки всех необходимых Python-библиотек:

```bash
pip install -r requirements.txt
```

## 3. Установка внешних инструментов

Фреймворк использует внешние инструменты для сбора информации. Их необходимо клонировать в папку `tools`.

### a. Создание папки `tools`

Если папка `tools` отсутствует в корне проекта, создайте ее.

### b. Установка Sublist3r

```bash
# Клонируем Sublist3r
git clone https://github.com/aboul3la/Sublist3r.git tools/sublist3r

# Устанавливаем его зависимости
pip install -r tools/sublist3r/requirements.txt
```

### c. Установка Sherlock

```bash
# Клонируем Sherlock
git clone https://github.com/sherlock-project/sherlock.git tools/sherlock

# Устанавливаем его зависимости
pip install -r tools/sherlock/requirements.txt
```

## 4. Запуск фреймворка

После выполнения всех шагов вы готовы к запуску. Убедитесь, что ваше виртуальное окружение активировано.

```bash
python main.py
```

Вы увидите главное меню, где сможете начать новое расследование.
